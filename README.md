# QA Project — Urban Routes

Proyecto de automatización de pruebas para la aplicación Urban Routes, cubriendo el flujo completo de solicitud de un taxi.

## Tecnologías utilizadas
- Python 3.14
- Selenium WebDriver
- Pytest
- Page Object Model (POM)

## Cómo ejecutar las pruebas
1. Instalar dependencias: `pip install selenium pytest`
2. Actualizar la URL del servidor en `data.py`
3. Ejecutar pruebas: `python -m pytest main.py -v`
